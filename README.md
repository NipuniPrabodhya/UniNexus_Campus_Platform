# UniNexus Campus Platform

A full-stack university platform developed. The system provides centralized student services, including individual contribution for the user management and a campus e-commerce marketplace.

## Features

### User Management
- Student registration
- User login and authentication
- Profile management
- Create, update, retrieve, and deactivate accounts

### Campus E-Commerce
- Add and manage product listings
- View available products
- View product details and seller information
- Update and delete listings
- Search, filter, and sort products
- Seller trust score
- Highlight popular listings
- Chat between users

## Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Architecture:** Full-Stack Web Application

## Project Structure

## How to Run

### Backend
cd backend > npm install > npm start

### Frontend
cd frontend > npm install > npm start
